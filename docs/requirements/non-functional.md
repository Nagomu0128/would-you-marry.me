# 非機能要件

「出典」は、プロダクトオーナーが最初に明示したもの（PO）、未決事項を決めたもの（D-xx）、本書で提案したもの（提案）を示す。
提案の項目はレビューで確定させる。

## 想定規模

| 項目 | 値 | 根拠 |
|---|---|---|
| 1 テナントあたりの参加者数 | 最大 200 名 | D-07 |
| 1 テナントあたりの写真枚数 | 最大 5,000 枚程度（1 人 20〜30 枚） | D-07 |
| 1 人あたりの投稿枚数の上限 | 100 枚 | D-26 |
| 1 テナントあたりの写真枚数の上限（理論値） | 20,000 枚 | 200 名 × 100 枚。全員が上限まで投稿した場合で、通常は上の想定（5,000 枚程度）に収まる |
| 写真 1 枚のファイルサイズ | 最大 10MB | D-12 |
| 1 テナントあたりの保存容量の目安 | 最大 25GB 程度 | 5,000 枚 × 平均 5MB と仮定した試算。縮小画像の分は含まない |
| ピーク時の同時アクセス数（1 テナント） | 最大 200 | 参加者全員が同時に使う場合 |
| 同じ日時に参加受付期間中のテナント数 | 数件まで | D-07 |
| データを保持する期間 | 開催日から 6 か月 | D-19 |
