# 機能要件: ユーザー画面

参加者（ゲスト）が使うユーザー画面の機能要件。

## 共通事項

- 「参加済み」とは、そのテナントの有効なセッションを持ち、ニックネームを登録済みであること
- FR-G-04 以降の機能は、参加済みの参加者だけが使える
- 使える期間（[テナントの期間](../overview.md#テナントの期間)）:
  - 新しく参加できるのは参加受付期間（開催日当日〜翌日）だけ
  - 参加済みの参加者は、閲覧期間の終わり（開催日の 3 か月後）まで、すべての機能を使える（D-23）
  - テナントが停止中の場合は、すべての機能を使えない
- どの機能も、参加者自身のテナントのデータだけを対象にする（[design/multi-tenancy.md](../design/multi-tenancy.md)）
- 他の参加者の投稿やいいね数の変化は、画面を再読み込みしたときに反映する（D-24）

---

## FR-G-01 参加（匿名認証）

- **概要**: 参加者が参加 URL（QR コード）からアクセスすると、匿名の参加者として登録され、セッショントークンがブラウザに保存される。
- **前提条件**:
  - 参加受付期間（開催日当日〜翌日）であり、テナントが停止中でない
  - 参加トークンが有効である（再発行で無効になっていない）
- **詳細**:
  - 参加者にパスワード、メールアドレス、外部アカウントを求めない
  - 参加トークンを検証し、有効なら新しい参加者（ゲスト ID）を発行して、そのテナントに紐づくセッショントークンをブラウザに保存する
  - 前提条件を満たさない場合はエラー画面（SG-E1）を表示する
  - 検証後は URL から参加トークンを取り除く（[design/auth.md](../design/auth.md)）
- **受け入れ条件**:
  - [ ] QR コードを読み取った後、追加の認証操作なしでニックネーム登録画面が表示される
  - [ ] 参加受付期間外、または無効な参加トークンではゲスト ID が発行されない
  - [ ] 発行されたセッションでは、そのテナントのデータにしかアクセスできない
- **関連**: US-G-01 / SG-01

## FR-G-02 セッションの保持と再訪

- **概要**: 一度参加したブラウザは、セッションが有効な間、QR コードを読み直さずに同じ参加者として使い続けられる。
- **詳細**:
  - セッションは閲覧期間の終わり（開催日の 3 か月後）まで有効。参加 URL が再発行されても無効にならない（D-08）
  - 参加 URL に再度アクセスしたとき、そのテナントの有効なセッションがあれば、新しい参加者を作らずに既存の参加者として扱う
  - ブラウザのデータを削除した場合や、別の端末で使う場合は引き継げない。QR コードを読み直して新しい参加者として参加する（D-09）
- **受け入れ条件**:
  - [ ] ブラウザを閉じて開き直しても、同じニックネームのまま使える
  - [ ] 同じブラウザで QR コードを読み直しても、参加者が重複して作られない
  - [ ] 閲覧期間が終わると、ユーザー画面を使えなくなる
- **関連**: US-G-01 / SG-01

## FR-G-03 ニックネームの登録・変更

- **概要**: 参加者は最初にニックネームを登録する。登録するまでホームに進めない。登録後はホームから変更できる。
- **詳細**:
  - ニックネーム未登録の参加者がユーザー画面のどのページにアクセスしても、ニックネーム登録画面に誘導する
  - 1〜20 文字（D-10）
  - 同じテナント内で、他の参加者が使っている名前は使えない。前後の空白を除いて比較する（仮置き）
  - 使用中の名前を入力した場合は「この名前は使われています」と表示し、別の名前を入力してもらう
  - 変更すると、過去に投稿した写真の投稿者名も新しい名前で表示される
- **受け入れ条件**:
  - [ ] ニックネームを登録しないとホームが表示されない
  - [ ] 空の名前、21 文字以上の名前は登録できない
  - [ ] 同じテナントで使用中の名前は登録・変更できない
  - [ ] 別のテナントで使われている名前は登録できる
  - [ ] ホームからニックネームを変更できる
- **関連**: US-G-02, US-G-10 / SG-02

## FR-G-04 ホーム

- **概要**: 参加済みの参加者が最初に見るページ。各ページへの入口を表示する。
- **詳細**:
  - 次の 4 ページへの導線を表示する: 席次表（SG-04）、料理のコース表（SG-05）、共有フォトアルバム（SG-06）、フォトアップロード（SG-07）
  - テナント名（結婚式の表示名）と、自分のニックネームを表示する。ニックネームの変更画面に進める
- **受け入れ条件**:
  - [ ] 4 ページすべてに、ホームから 1 タップで移動できる
- **関連**: US-G-02, US-G-03 / SG-03

## FR-G-05 オンライン席次表

- **概要**: テナントに登録された席次表 PDF を、ページ内にインライン表示する。
- **詳細**:
  - 表示する PDF は管理面で登録したもの（FR-A-05）
  - スマートフォンで拡大・スクロールして読める
  - 未登録の場合は準備中である旨を表示する（仮置き）
- **受け入れ条件**:
  - [ ] 別のアプリに切り替えずに、ページ内で席次表を閲覧できる
  - [ ] 他のテナントの席次表は表示されない
- **関連**: US-G-04 / SG-04

## FR-G-06 料理のコース表

- **概要**: テナントに登録された料理のコース表の画像を表示する静的ページ（D-17）。
- **詳細**:
  - 表示する画像は管理面で登録したもの（FR-A-06）。複数枚ある場合は登録した順に並べる
  - スマートフォンで拡大して読める
  - 参加者は閲覧のみ
  - 未登録の場合は準備中である旨を表示する（仮置き）
- **受け入れ条件**:
  - [ ] そのテナントのコース表の画像が表示される
- **関連**: US-G-05 / SG-05

## FR-G-07 フォトアップロード

- **概要**: 参加者が写真を選んでアップロードし、共有フォトアルバムに投稿する。
- **詳細**:
  - 写真のみ。動画はアップロードできない（D-12）
  - 1 回の操作で 1 枚ずつアップロードする。端末のカメラで撮影するか、端末内の写真から選ぶ
  - オリジナルのまま送信する。1 枚 10MB まで（D-12）
  - 位置情報などのメタデータはアップロード時に取り除く（D-25）
  - アップロードした写真は、同じテナントの共有フォトアルバムに、投稿者のニックネームとともに表示される（D-11）
  - 送信の進捗を表示する。回線が不安定でも、失敗したことが分かり、再試行できる（NFR-10）
  - 1 人あたりの投稿枚数の上限は設けない（仮置き、[OQ-20](../open-questions.md)）
- **受け入れ条件**:
  - [ ] アップロードが完了した写真がタイムラインに表示される
  - [ ] アップロードの進捗と成功・失敗が参加者に分かる
  - [ ] 画像以外のファイルと、10MB を超えるファイルはアップロードできない
  - [ ] アップロードした写真から位置情報が取り除かれている
- **関連**: US-G-06 / SG-07

## FR-G-08 共有フォトアルバム

- **概要**: テナント内の参加者が投稿した写真を見るページ。「タイムライン」と「ランキング」の 2 タブで構成する。
- **詳細**:
  - 最初に表示するタブはタイムライン（仮置き）
  - 表示する写真は同じテナントのものだけ
  - 写真をタップすると拡大表示し、いいね・保存・（自分の写真なら）削除ができる
  - 再読み込みの操作（画面を引っ張るなど）で最新の状態に更新できる（D-24）
- **受け入れ条件**:
  - [ ] 2 つのタブを切り替えて表示できる
  - [ ] 再読み込みすると、他の参加者の新しい投稿といいね数の変化が反映される
- **関連**: US-G-07 / SG-06

## FR-G-09 タイムラインタブ

- **概要**: すべての参加者が投稿した写真を一覧表示する。
- **詳細**:
  - 並び順は投稿の新しい順
  - 各写真に、投稿者のニックネーム（D-11）といいね数を表示する
  - 一覧は縮小画像で表示し、枚数が多くても表示が重くならないよう段階的に読み込む（NFR-07）
- **受け入れ条件**:
  - [ ] 自分を含むすべての参加者の写真が、新しい順に表示される
  - [ ] 他のテナントの写真は表示されない
- **関連**: US-G-08 / SG-06

## FR-G-10 いいね

- **概要**: 参加者は写真に「いいね」を付けられる（D-15）。
- **詳細**:
  - 自分の写真にも、他の参加者の写真にも付けられる
  - 1 人の参加者が同じ写真に付けられるいいねは 1 回まで
  - いいねを取り消せる
  - タイムラインタブ・ランキングタブのどちらからも付けられる
  - 自分がいいね済みかどうかが分かるように表示する
  - いいね数はランキング（FR-G-12）の集計に使う
- **受け入れ条件**:
  - [ ] いいねすると、その写真のいいね数が 1 増える
  - [ ] 同じ写真に 2 回目のいいねはできない
  - [ ] いいねを取り消すと、いいね数が 1 減る
  - [ ] 他のテナントの写真にはいいねできない
- **関連**: US-G-08, US-G-09 / SG-06

## FR-G-11 写真の保存

- **概要**: 参加者は、タイムラインタブ・ランキングタブに表示された写真を自分の端末に保存できる。
- **詳細**:
  - 保存できるのはオリジナル画質の画像（位置情報などは取り除き済み）（D-25）
  - iOS / Android のブラウザから端末に保存できる手段を用意する
- **受け入れ条件**:
  - [ ] タイムラインタブとランキングタブのどちらからも保存できる
  - [ ] 保存した画像を端末上で開ける
  - [ ] 保存した画像に位置情報が含まれていない
- **関連**: US-G-08, US-G-09 / SG-06

## FR-G-12 ランキングタブ

- **概要**: いいね数の多い写真を上位 10 枚まで表示する（D-16）。
- **詳細**:
  - いいね数の多い順に並べる。いいね数が同じ場合は、先に投稿された写真を上にする
  - いいね 0 件の写真は載せない
  - 各写真に順位、いいね数、投稿者のニックネームを表示する
  - 集計対象は同じテナントの写真だけ
- **受け入れ条件**:
  - [ ] いいね数の多い順に、最大 10 枚が表示される
  - [ ] いいね数が同じ写真は、先に投稿されたものが上に表示される
  - [ ] いいね 0 件の写真は表示されない
  - [ ] 写真にいいね・保存できる（FR-G-10, FR-G-11）
- **関連**: US-G-07, US-G-09 / SG-06

## FR-G-13 自分の写真の削除

- **概要**: 参加者は、自分が投稿した写真を削除できる（D-13）。
- **詳細**:
  - 削除できるのは、今のセッションの参加者が投稿した写真だけ。セッションを失う前に投稿した写真は削除できない（D-09）
  - 削除の前に確認を求める
  - 削除した写真は、アルバムと新郎新婦用ページから消える。その写真へのいいねも削除する
- **受け入れ条件**:
  - [ ] 自分の写真を削除できる
  - [ ] 他の参加者の写真には削除の操作が表示されず、削除もできない
  - [ ] 削除した写真はタイムライン・ランキングに表示されない
- **関連**: US-G-11 / SG-06
