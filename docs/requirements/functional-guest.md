# 機能要件: ユーザー画面

参加者（ゲスト）が使うユーザー画面の機能要件。

## 共通事項

- 「参加済み」とは、そのテナントの有効なセッションを持ち、ニックネームを登録済みであること
- FR-G-04 以降の機能は、参加済みの参加者だけが使える
- どの機能も、参加者自身のテナントのデータだけを対象にする（[design/multi-tenancy.md](../design/multi-tenancy.md)）

---

## FR-G-01 参加（匿名認証）

- **概要**: 参加者が参加 URL（QR コード）からアクセスすると、匿名の参加者として登録され、セッショントークンがブラウザに保存される。
- **前提条件**:
  - テナントが参加を受け付ける状態である（[OQ-17](../open-questions.md)）
  - 参加トークンが有効である（[OQ-02](../open-questions.md)）
- **詳細**:
  - 参加者にパスワード、メールアドレス、外部アカウントを求めない
  - 参加トークンを検証し、有効なら新しい参加者（ゲスト ID）を発行して、そのテナントに紐づくセッショントークンをブラウザに保存する
  - 参加トークンが無効・期限切れの場合や、テナントが参加を受け付けていない場合は、エラー画面（SG-E1）を表示する
  - 検証後は URL から参加トークンを取り除く（[design/auth.md](../design/auth.md)）
- **受け入れ条件**:
  - [ ] QR コードを読み取った後、追加の認証操作なしでニックネーム登録画面が表示される
  - [ ] 無効な参加トークンではゲスト ID が発行されない
  - [ ] 発行されたセッションでは、そのテナントのデータにしかアクセスできない
- **関連**: US-G-01 / SG-01

## FR-G-02 セッションの保持と再訪

- **概要**: 一度参加したブラウザは、セッションが有効な間、QR コードを読み直さずに同じ参加者として使い続けられる。
- **詳細**:
  - 参加 URL に再度アクセスしたとき、そのテナントの有効なセッションがあれば、新しい参加者を作らずに既存の参加者として扱う
  - セッションの有効期間は [OQ-02](../open-questions.md)
  - ブラウザのデータを削除した場合や、別の端末で使う場合の扱いは [OQ-03](../open-questions.md)
- **受け入れ条件**:
  - [ ] ブラウザを閉じて開き直しても、同じニックネームのまま使える
  - [ ] 同じブラウザで QR コードを読み直しても、参加者が重複して作られない
- **関連**: US-G-01 / SG-01

## FR-G-03 ニックネーム登録

- **概要**: 参加者は最初にニックネームを登録する。登録するまでホームに進めない。
- **詳細**:
  - ニックネーム未登録の参加者がユーザー画面のどのページにアクセスしても、ニックネーム登録画面に誘導する
  - 文字数・使用できる文字・重複の可否・後からの変更可否は [OQ-04](../open-questions.md)
- **受け入れ条件**:
  - [ ] ニックネームを登録しないとホームが表示されない
  - [ ] 空のニックネームは登録できない
  - [ ] 登録するとホームに遷移する
- **関連**: US-G-02 / SG-02

## FR-G-04 ホーム

- **概要**: 参加済みの参加者が最初に見るページ。各ページへの入口を表示する。
- **詳細**:
  - 次の 4 ページへの導線を表示する: 席次表（SG-04）、料理のコース表（SG-05）、共有フォトアルバム（SG-06）、フォトアップロード（SG-07）
  - テナント名（結婚式の表示名）を表示する（仮置き）
- **受け入れ条件**:
  - [ ] 4 ページすべてに、ホームから 1 タップで移動できる
- **関連**: US-G-02, US-G-03 / SG-03

## FR-G-05 オンライン席次表

- **概要**: テナントに登録された席次表 PDF を、ページ内にインライン表示する。
- **詳細**:
  - 表示する PDF は管理面で登録したもの（FR-A-05）
  - スマートフォンで拡大・スクロールして読める
  - 未登録の場合は準備中である旨を表示する（仮置き）
- **受け入れ条件**:
  - [ ] 別のアプリに切り替えずに、ページ内で席次表を閲覧できる
  - [ ] 他のテナントの席次表は表示されない
- **関連**: US-G-04 / SG-04

## FR-G-06 料理のコース表

- **概要**: テナントごとの料理のコース表を静的ページとして表示する。
- **詳細**:
  - 参加者は閲覧のみ
  - 内容の登録方法は [OQ-11](../open-questions.md)（FR-A-06）
- **受け入れ条件**:
  - [ ] そのテナントのコース内容が表示される
- **関連**: US-G-05 / SG-05

## FR-G-07 フォトアップロード

- **概要**: 参加者が写真を選んでアップロードし、共有フォトアルバムに投稿する。
- **詳細**:
  - 端末のカメラで撮影するか、端末内の写真から選んでアップロードする（仮置き）
  - アップロードした写真は、同じテナントの共有フォトアルバムに表示される
  - どの参加者が投稿したかを記録する。アルバム上で投稿者のニックネームを表示するかは [OQ-05](../open-questions.md)
  - 動画への対応、ファイルサイズの上限、複数枚の同時アップロードは [OQ-06](../open-questions.md)
  - 投稿した写真の削除は [OQ-07](../open-questions.md)
  - 回線が不安定でも、失敗したことが分かり、再試行できる（NFR-10）
- **受け入れ条件**:
  - [ ] アップロードが完了した写真がタイムラインに表示される
  - [ ] アップロードの成功・失敗が参加者に分かる
  - [ ] 画像以外のファイルはアップロードできない
- **関連**: US-G-06 / SG-07

## FR-G-08 共有フォトアルバム

- **概要**: テナント内の参加者が投稿した写真を見るページ。「タイムライン」と「ランキング」の 2 タブで構成する。
- **詳細**:
  - 最初に表示するタブはタイムライン（仮置き）
  - 表示する写真は同じテナントのものだけ
- **受け入れ条件**:
  - [ ] 2 つのタブを切り替えて表示できる
- **関連**: US-G-07 / SG-06

## FR-G-09 タイムラインタブ

- **概要**: すべての参加者が投稿した写真を一覧表示する。
- **詳細**:
  - 並び順は投稿の新しい順（仮置き）
  - 一覧は縮小画像で表示し、タップすると拡大表示する（仮置き）
  - 各写真のいいね数を表示する（仮置き）
  - 枚数が多くても表示が重くならないよう、段階的に読み込む（NFR-07）
  - 他の参加者の新しい投稿をいつ反映するか（リアルタイム / 再読み込み時）は [OQ-18](../open-questions.md)
- **受け入れ条件**:
  - [ ] 自分を含むすべての参加者の写真が表示される
  - [ ] 他のテナントの写真は表示されない
- **関連**: US-G-08 / SG-06

## FR-G-10 いいね

- **概要**: 参加者は、他の参加者が投稿した写真に「いいね」を付けられる。
- **詳細**:
  - 1 人の参加者が同じ写真に付けられるいいねは 1 回まで
  - 自分がいいね済みかどうかが分かるように表示する
  - いいね数はランキング（FR-G-12）の集計に使う
  - 自分の写真へのいいね、いいねの取り消し、ランキングタブからのいいねは [OQ-09](../open-questions.md)
- **受け入れ条件**:
  - [ ] いいねすると、その写真のいいね数が 1 増える
  - [ ] 同じ写真に 2 回目のいいねをしても、いいね数は増えない
  - [ ] 他のテナントの写真にはいいねできない
- **関連**: US-G-08 / SG-06

## FR-G-11 写真の保存

- **概要**: 参加者は、タイムラインタブ・ランキングタブに表示された写真を自分の端末に保存できる。
- **詳細**:
  - iOS / Android のブラウザから端末に保存できる手段を用意する
  - 保存する画像の画質（オリジナル / 縮小版）と、位置情報などのメタデータの扱いは [OQ-19](../open-questions.md)
- **受け入れ条件**:
  - [ ] タイムラインタブとランキングタブのどちらからも保存できる
  - [ ] 保存した画像を端末上で開ける
- **関連**: US-G-08, US-G-09 / SG-06

## FR-G-12 ランキングタブ

- **概要**: 写真をいいね数の多い順に並べて表示する。
- **詳細**:
  - 各写真のいいね数を表示する
  - 集計対象は同じテナントの写真だけ
  - 表示件数（全件 / 上位 N 件）と、いいね数が同じ場合の並び順は [OQ-10](../open-questions.md)
  - いいね数の変化をいつ反映するかは [OQ-18](../open-questions.md)
- **受け入れ条件**:
  - [ ] いいね数の多い順に並ぶ
  - [ ] 写真を保存できる（FR-G-11）
- **関連**: US-G-07, US-G-09 / SG-06
