# 機能要件: 新郎新婦用ページ

新郎新婦が使う新郎新婦用ページの機能要件（D-18）。管理面とは別のページとして提供する。

## 共通事項

- 新郎新婦用ページは、管理者が発行した専用 URL とパスコードで入る（FR-A-12）
- 使える期間: 専用 URL の発行から、データ削除（開催日の 6 か月後）まで。参加者が閲覧できなくなった後も使える（[テナントの期間](../overview.md#テナントの期間)）
- テナントが停止中の場合は使えない
- 対象は自分たちのテナントのデータだけ（[design/multi-tenancy.md](../design/multi-tenancy.md)）
- できないこと: 写真の投稿・削除、いいね、一括ダウンロード、席次表やコース表の編集
- 参加者の投稿やいいね数の変化は、画面を再読み込みしたときに反映する（D-24）

---

## FR-C-01 新郎新婦用ページへの入場

- **概要**: 新郎新婦は、専用 URL を開いてパスコードを入力すると、新郎新婦用ページに入れる。
- **詳細**:
  - 専用 URL のトークンを検証し、有効ならパスコードの入力画面を表示する
  - パスコードが一致すれば、そのテナントに紐づく新郎新婦のセッションをブラウザに保存する
  - パスコードの入力を連続して間違えた場合は、しばらく入力できなくする（仮置き: 5 回失敗で 15 分）
  - セッションはデータ削除（開催日の 6 か月後）まで有効（仮置き）
  - 入場後は URL からトークンを取り除く（[design/auth.md](../design/auth.md)）
  - トークンが無効・期間外・テナント停止中の場合はエラー画面（SC-E1）を表示する
- **受け入れ条件**:
  - [ ] 正しい専用 URL とパスコードで新郎新婦用ページに入れる
  - [ ] パスコードが違うと入れない
  - [ ] パスコードを連続して間違えると、一定時間入力できなくなる
  - [ ] 一度入ったブラウザでは、次回からパスコードの入力なしで使える
  - [ ] 新郎新婦のセッションでは、他のテナントのデータにアクセスできない
- **関連**: US-C-01 / SC-01

## FR-C-02 写真一覧

- **概要**: 参加者が投稿したテナントの写真を一覧表示する。
- **詳細**:
  - 並び順は投稿の新しい順
  - 各写真に、投稿者のニックネームといいね数を表示する
  - 一覧は縮小画像で表示し、段階的に読み込む。タップすると拡大表示する
- **受け入れ条件**:
  - [ ] テナントのすべての写真が新しい順に表示される
  - [ ] 削除された写真は表示されない
- **関連**: US-C-02 / SC-02

## FR-C-03 いいね数・ランキングの確認

- **概要**: 写真のいいね数と、参加者向けと同じランキングを確認できる。
- **詳細**:
  - ランキングの内容は参加者向けのランキングタブ（FR-G-12）と同じ（上位 10 枚、同数なら先に投稿された写真が上）
  - 新郎新婦はいいねを付けられない
- **受け入れ条件**:
  - [ ] 参加者に表示されるものと同じランキングが表示される
- **関連**: US-C-03 / SC-02

## FR-C-04 投稿者での絞り込み

- **概要**: 投稿者（ニックネーム）を選んで、その人の写真だけを表示する。
- **詳細**:
  - 写真を投稿した参加者のニックネームを一覧から選ぶ
  - 絞り込みを解除すると、すべての写真の一覧に戻る
- **受け入れ条件**:
  - [ ] 投稿者を選ぶと、その人が投稿した写真だけが表示される
- **関連**: US-C-04 / SC-02

## FR-C-05 写真の保存

- **概要**: 写真を 1 枚ずつ端末に保存できる。
- **詳細**:
  - 参加者の保存（FR-G-11）と同じく、オリジナル画質（位置情報などは取り除き済み）
  - 一括ダウンロードは提供しない（D-18）
- **受け入れ条件**:
  - [ ] 一覧・ランキング・絞り込み結果のどこからでも、写真を 1 枚ずつ保存できる
- **関連**: US-C-05 / SC-02
