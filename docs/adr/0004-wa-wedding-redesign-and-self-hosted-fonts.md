# ADR-0004: 和の婚礼の意匠への再構成と、Web フォントの自前配信

- ステータス: 承認
- 日付: 2026-10-21
- 関連: ADR-0002 / NFR-10, NFR-24, NFR-26 / [spec/design-guide.md](../spec/design-guide.md)

## コンテキスト

- 2026-10-21 の UI（The Wedding Journal）は、英字の大文字見出し・イタリックの決まり文句・端末フォントの中間ウェイトの多用などで「AI が作った画面」に見えるという指摘を受けた
- プロダクトオーナーの方針: 披露宴の画面として、より豪華で華やかにする。リッチなモーショングラフィックスを導入し、ニックネームの入力は記帳した紙が折り鶴に折られて飛んでいく演出にする。フォントとウェイトは必ず見直す
- 旧デザインガイドは「外部 Web フォントを読み込まない」としていた。端末のフォントだけでは、明朝・筆文字の表情を出せない

## 選択肢

| 論点 | 選択肢 | 結論 |
|---|---|---|
| 意匠 | 洋風のエディトリアル（旧） / 洋風のラグジュアリー（シャンパンゴールド・スクリプト体） / 和の婚礼（和紙・紅・金・水引・折り鶴） | 和の婚礼。折り鶴の演出と一貫し、日本の披露宴の紙もの（招待状・芳名帳・席札・祝儀袋）と地続きになる |
| フォント | 端末のフォントのみ / Google Fonts の CDN / fontsource で自前配信 | fontsource で自前配信。同一オリジンから配信でき、unicode-range の分割で使う文字の分だけ読み込む。CDN への依存と第三者への通信を増やさない |
| 演出 | Lottie・動画 / Motion と SVG | Motion と SVG（ADR-0002 を継続）。折り鶴は SVG の面の変形と 3D の transform で描く |

## 決定

- 意匠は「寿ぎ（Kotohogi）」。和紙・墨・紅・金・水引（あわじ結び）・折り鶴・青海波。詳細は design-guide.md
- フォントは しっぽり明朝 B1（500 / 800）、Zen Kaku Gothic New（400 / 700）、Yuji Syuku（400）、Bodoni Moda（可変、数字のみ）。`@fontsource` のパッケージを packages/ui の依存に入れ、テーマの CSS から読み込む。`font-display: swap`
- 演出は design-guide.md「モーション」の一覧のとおり。全画面の演出はスキップでき、動きを減らす設定では省く

## 影響

- 初回表示でフォントを待たない（swap）。フォントの取得は画面で使う文字の分割ファイルだけ（明朝 1 ファイル平均 約 56KB、ゴシック 約 19KB）。式場の回線でも本文は端末のフォントで先に読める
- 配信物にフォントのファイルが増える（ビルドの出力が大きくなる）。Workers の静的アセットとして配信し、ハッシュ付きの名前で長くキャッシュされる
- 旧デザインガイドの「外部 Web フォントを読み込まない」は「外部 CDN から読み込まない」に改める
