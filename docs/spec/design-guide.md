# デザインガイド（案）

ユーザー画面・新郎新婦用ページ・管理面で共通に使う、見た目と動きのルール。
画面ごとの構成は [screen-details.md](screen-details.md)、文言は [messages.md](messages.md) を参照。

## コンセプト

- **上品で温かい、式の余韻を楽しむアルバム**: 紙のような背景、落ち着いた文字色、シャンパンゴールドの差し色
- **写真が主役**: 画面の装飾は控えめにし、華やかさは動き（Motion）で出す
- **迷わない**: 1 画面 1 目的。説明を読まなくても使える

| 背景 | Ivory | `#FBF8F3` | |

| 文字（主） | Charcoal | `#2B2725` | 背景とのコントラスト比 約 14:1 |
| 文字（補助） | Warm Gray | `#6F6660` | 約 5.3:1 |
| 区切り線 | Sand | `#E8E1D6` | |
| 主要ボタン | Charcoal | `#2B2725` | 文字は白 |
| 差し色（装飾） | Champagne | `#B8935A` | 線・アイコン・モーション用。文字には使わない |
| 差し色（文字） | Deep Gold | `#8A6A35` | 約 4.7:1 |

- 初版はライトテーマのみ（仮置き）

## 文字

| 用途 | フォント |
|---|---|
| 和文（すべて） | 端末標準のゴシック体: `-apple-system, BlinkMacSystemFont, "Hiragino Sans", "Noto Sans JP", sans-serif` |
| 欧文のアクセント（見出しの英字・日付・順位） | Cormorant Garamond（Google Fonts） |

- 和文の Web フォントは読み込まない（ファイルが大きく、式場の回線で表示が遅れるため）

| 種類 | サイズ | 太さ | 行間 |
|---|---|---|---|
| 見出し（大） | 24px | 600 | 1.4 |
| 見出し（中） | 20px | 600 | 1.4 |
| 本文 | 16px | 400 | 1.7 |
| 補助 | 14px | 400 | 1.6 |
| キャプション | 12px | 400 | 1.5 |

- 入力欄は 16px 以上（iPhone の Safari で入力時に画面が拡大されるのを防ぐ）
- 端末の文字サイズ設定を大きくしても崩れないようにする

## 余白・形

- 余白は 4px 単位（4・8・12・16・24・32・48）
- 画面の左右の余白は 16px
- 角丸: ボタン・入力欄 12px、カード 16px、一覧の写真 4px
- 影はカードだけに控えめに付ける（`0 2px 8px rgba(43, 39, 37, 0.06)`）

## レイアウト

- 幅 375px（iPhone の標準的な幅）を基準に設計し、320px でも崩れないようにする
- PC では中央に寄せ、最大幅はユーザー画面・新郎新婦用ページが 560px、管理面が 960px
- ユーザー画面は、画面下部に固定のナビゲーションを置く: **ホーム / アルバム / 投稿 / 席次表 / 料理**。「投稿」は中央で目立たせる（仮置き）
- 画面の上下は、iPhone の切り欠きとホームバー（セーフエリア）を避ける
- 写真の一覧は 3 列のグリッド、間隔 2px、正方形に切り抜いて表示する
- 写真の拡大表示は全画面・黒背景。左右のスワイプで前後の写真、下へのスワイプで閉じる（仮置き）

## 部品

| 部品 | ルール |
|---|---|
| ボタン | 主要（Charcoal の塗り）、補助（枠線）、テキストの 3 種類。高さ 48px。押すと少し縮む |
| 入力欄 | 高さ 48px、文字 16px。エラーは欄の下に Error 色で表示 |
| タブ | 選択中のタブの下線（Champagne）がスライドして移動する |
| カード | White、角丸 16px、影あり。ホームの各ページへの入口に使う |
| トースト | 画面下部（ナビゲーションの上）に 3 秒表示 |
| 確認ダイアログ | 画面下から出るシート。危険な操作のボタンは Error 色 |
| 読み込み中 | 内容の形をした薄いブロック（スケルトン）。くるくる回る表示は使わない |
| アイコン | 線のアイコン（Lucide など）、線幅 1.5 |

## モーション

アニメーションには Motion（旧 Framer Motion）を使う（[ADR-0002](../adr/0002-use-motion-for-animation.md)）。

### 原則

- **短く**: 画面の動きは 150〜300ms。演出（モーショングラフィックス）は 3 秒以内
- **邪魔しない**: 演出中も操作を止めない。演出はタップで飛ばせる
- **端末の設定に従う**: 「視差効果を減らす」（動きを減らす）が有効なら、移動や拡大の動きをやめてフェードだけにし、演出は表示しない（NFR-26）
- **軽く**: 動かすのは transform と opacity だけにする（古い端末でも滑らかにするため）

### 動きの一覧（案）

| 場面 | 動き | 種類 |
|---|---|---|
| 初めてのホーム表示（ニックネーム登録の直後） | ウェルカム演出。テナント名、リング、花びらなど（2〜3 秒） | モーショングラフィックス |
| いいね | ハートが弾み、小さな粒が広がる | モーショングラフィックス（短） |
| アップロード完了 | チェックマークが描かれ、紙吹雪が少し舞う | モーショングラフィックス（短） |
| ランキングの表示 | 3 位 → 2 位 → 1 位の順に登場し、1 位に王冠が載る | モーショングラフィックス |
| 新郎新婦用ページに初めて入ったとき | 二人へのお祝いの演出（2〜3 秒） | モーショングラフィックス |
| 画面の切り替え | フェードしながら少し上へ（8px） | 画面の動き |
| タブの切り替え | 下線のスライド、内容のフェード | 画面の動き |
| 写真の拡大 | 一覧の位置から全画面へ広がる | 画面の動き |
| 写真の一覧の読み込み | 読み込めた写真から順にフェードイン | 画面の動き |
| ボタン | 押したときに少し縮む | 画面の動き |

### モーショングラフィックスの作り方

- Claude で作成し、SVG と Motion で書いた React コンポーネントとしてアプリに組み込む。動画ファイルや Lottie は使わない（仮置き）
- 置き場所は `packages/ui/src/motion/`。1 つの演出を 1 つのコンポーネントにする
- 演出の終了を `onComplete` で知らせる。動きを減らす設定のときは何も表示せず、すぐに終了を知らせる
- 色はこのガイドの色を使う。ウェルカム演出にはテナント名を差し込めるようにする

## 文言のトーン

- です・ます調で、やわらかく、短く
- 専門用語（セッション、トークンなど）は画面に出さない
- 文言は [messages.md](messages.md) にまとめる（NFR-21）

## アクセシビリティ

- タップできる領域は 44px 四方以上（NFR-06）
- 写真には代替テキストを付ける（「たろう さんの写真」）
- 色だけで状態を伝えない（いいね済みはハートの塗りでも区別する）
