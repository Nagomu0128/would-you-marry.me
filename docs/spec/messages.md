# 文言・メッセージ一覧

画面に表示する文言をまとめる。実装では、この一覧と同じ内容を文言ファイルにまとめて持つ（NFR-21）。
`{name}` のような部分には値を差し込む。トーンは [design-guide.md](design-guide.md#文言のトーン) に従う。

## エラー（API の code ごと）

| code | 参加者向けの文言 | 新郎新婦向けの文言 | 表示する場所 |
|---|---|---|---|
| `UNAUTHENTICATED` | 受付でお渡しした QR コードを読み取ってください | 管理者からお知らせした URL を開いてください | SG-E1 / SC-E1 |
| `TENANT_NOT_FOUND` | この結婚式のページは見つかりませんでした | 同左 | SG-E1 / SC-E1 |
| `TENANT_SUSPENDED` | 現在ご利用いただけません。しばらくしてからお試しください | 同左 | SG-E1 / SC-E1 |
| `OUTSIDE_JOINING_PERIOD` | 参加の受付期間ではありません。受付は結婚式の当日と翌日です | — | SG-E1 |
| `PERIOD_ENDED` | 公開期間が終了しました。ご参加ありがとうございました | 公開期間が終了しました。ご利用ありがとうございました | SG-E1 / SC-E1 |
| `JOIN_TOKEN_INVALID` | この QR コードは使えなくなっています。会場のスタッフにお問い合わせください | — | SG-E1 |
| `NICKNAME_TAKEN` | この名前は使われています。別の名前を入力してください | — | SG-02 |
| `TERMS_NOT_AGREED` | 利用規約とプライバシーポリシーへの同意が必要です | 同左 | SG-02 / SC-01 |
| `FILE_TOO_LARGE` | 写真のサイズが大きすぎます（10MB まで） | — | SG-07 |
| `UNSUPPORTED_FILE_TYPE` | この形式の写真は投稿できません（JPEG・PNG のみ） | — | SG-07 |
| `UPLOAD_LIMIT_REACHED` | 投稿できる枚数（100 枚）に達しました | — | SG-07 |
| `COUPLE_LINK_INVALID` | — | この URL は使えなくなっています。管理者にお問い合わせください | SC-E1 |
| `PASSCODE_INVALID` | — | パスコードが違います（あと {remainingAttempts} 回） | SC-01 |
| `PASSCODE_LOCKED` | — | 入力できる回数を超えました。約 {minutes} 分後にお試しください | SC-01 |
| `FORBIDDEN` | この操作はできません | 同左 | トースト |
| `NOT_FOUND` | 見つかりませんでした。削除された可能性があります | 同左 | トースト |
| `RATE_LIMITED` | アクセスが集中しています。少し時間をおいてお試しください | 同左 | SG-E1 / トースト |
| `INTERNAL_ERROR` | エラーが発生しました。時間をおいてもう一度お試しください | 同左 | トースト |
| （通信エラー） | 通信できませんでした。電波の良い場所でもう一度お試しください | 同左 | 画面内 + 「もう一度試す」 |

`NICKNAME_REQUIRED` は文言を出さず、ニックネーム登録画面（SG-02）へ移動する。

### 入力エラー（`VALIDATION_ERROR` の項目ごと）

| 項目 | 内容 | 文言 |
|---|---|---|
| ニックネーム | 空 | ニックネームを入力してください |
| ニックネーム | 21 文字以上 | ニックネームは 20 文字以内で入力してください |
| パスコード | 空 | パスコードを入力してください |
| テナント名（管理） | 空・51 文字以上 | テナント名を 1〜50 文字で入力してください |
| 開催日（管理） | 空・不正 | 開催日を選んでください |
| 削除の確認（管理） | 不一致（`CONFIRMATION_MISMATCH`） | テナント名が一致しません |
