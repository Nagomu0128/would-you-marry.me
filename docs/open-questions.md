# 未決事項・決定済み事項

決まったものは「未決事項」から「決定済み事項」に移し、影響するドキュメントを更新する。

## 未決事項

| ID | 論点 | 内容・選択肢 | 影響する箇所 |
|---|---|---|---|
| OQ-01 | 想定規模 | 1 テナントあたりの参加者数・写真枚数、ピーク時の同時アクセス数、同じ日時に公開中になるテナント数 | NFR-08、[non-functional.md](requirements/non-functional.md) の想定規模、技術選定 |
| OQ-02 | 参加 URL とセッションの有効期間 | 参加トークンをいつからいつまで有効にするか（例: 開催日の前日〜翌日）。セッションの有効期間。参加 URL を再発行したとき、参加済みの参加者のセッションを維持するか（仮置き: 維持する） | FR-A-07, FR-A-08, FR-G-01, FR-G-02 |
| OQ-03 | セッションを失ったときの扱い | ブラウザのデータ削除や別端末での利用で、別の参加者として再参加になる。投稿した写真やいいねを引き継ぐ手段（例: 引き継ぎコード）が必要か | FR-G-02、[auth.md](design/auth.md) |
| OQ-04 | ニックネームのルール | 文字数・使用できる文字、同じテナント内での重複の可否、後から変更できるか | FR-G-03 |
| OQ-05 | 投稿者の表示 | 共有フォトアルバムで、写真の投稿者のニックネームを表示するか | FR-G-07, FR-G-09 |
| OQ-06 | アップロードの仕様 | 動画も対象にするか、1 ファイルのサイズ上限、複数枚の同時アップロード、1 人あたりの上限枚数 | FR-G-07, NFR-07 |
| OQ-07 | 投稿者による写真の削除 | 参加者が自分の投稿した写真を削除できるか | FR-G-07、[auth.md](design/auth.md) の認可 |
| OQ-08 | 写真のモデレーション | 不適切な写真を管理者（または新郎新婦）が非表示・削除できるようにするか | [functional-admin.md](requirements/functional-admin.md)、[auth.md](design/auth.md) の認可 |
| OQ-09 | いいねのルール | 自分の写真へのいいね、いいねの取り消し、ランキングタブからのいいねを許可するか | FR-G-10 |
| OQ-10 | ランキングの仕様 | 表示件数（全件 / 上位 N 件）、いいね数が同じときの並び順（例: 先に投稿された順） | FR-G-12 |
| OQ-11 | 料理のコース表の入力方法 | 管理面で料理を 1 品ずつ入力する / 自由記述 / テナントごとに固定ページを用意する | FR-A-06, FR-G-06 |
| OQ-12 | 新郎新婦向けの役割 | 新郎新婦（または代理人）が、コンテンツの登録・写真の一括ダウンロード・モデレーションなどをできる役割が必要か | [overview.md](overview.md)、[auth.md](design/auth.md) |
| OQ-13 | データ保持と式後の閲覧 | 式の後、参加者が閲覧・保存できる期間。写真などのデータを削除する時期と方法 | NFR-17, FR-A-04、技術選定 |
| OQ-14 | 監視の範囲 | 収集するログ・メトリクスの項目、保持期間、アラート条件。管理面の画面で見るか、外部の監視ツールで見るか | FR-A-09, FR-A-10 |
| OQ-15 | 多言語対応 | 海外からの参加者のために、英語などに対応するか | [non-functional.md](requirements/non-functional.md) |
| OQ-16 | 管理者の許可リストの管理 | 最初の管理者をどう登録するか。管理面から管理者を追加・削除できるようにするか | FR-A-01 |
| OQ-17 | テナントの状態 | 状態（準備中 / 公開中 / 終了 は仮置き）の定義と、状態ごとに参加・閲覧・投稿を許可するか。開催日に合わせて自動で切り替えるか | FR-A-03, FR-A-04, FR-G-01 |
| OQ-18 | アルバムの更新方式 | 他の参加者の投稿やいいね数の変化を、リアルタイムに反映するか、再読み込みしたときに反映するか | FR-G-09, FR-G-12、技術選定 |
| OQ-19 | 保存する画像とメタデータ | 保存するときの画質（オリジナル / 縮小画像）。位置情報などのメタデータを取り除くか | FR-G-11, NFR-16 |
